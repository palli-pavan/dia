## Run

Extract the complete source ZIP. On a computer with Python 3.13 and the dependencies installed, open START_PROJECT.cmd. The API and prebuilt React dashboard run together at http://127.0.0.1:8008/.

For first installation use SETUP_PROJECT.cmd, or install requirements-tested.txt from emergency-resource-allocation. The included frontend/dist is already built; Node.js is needed for rebuilding.

Use Describe, AI analysis, Response plan, What-if & audit and Donations & funds to demonstrate the project. Load custom-location demo for six editable Andhra locations. A fresh installation starts with an empty local fund ledger. The INR 7 lakh entry shown in the report is a synthetic demonstration on the review computer.

## Scope

The model and demonstration observations use synthetic data. Dispatch steps are local confirmations, and the fund module does not collect or transfer payments. The implementation is a local prototype; cloud deployment is future work.
